# 3D asset attribution

`arduino-uno/arduino-uno.glb` is a reference CAD asset mirrored from the
vendored `external/velxio` asset registry in this repository. That registry is
dual-licensed under AGPL-3.0-or-later / a commercial license; see
`external/velxio/LICENSE` and `external/velxio/COMMERCIAL_LICENSE.md` before
using this asset in a hosted proprietary deployment.

The Wireup admin preview applies only runtime presentation (lighting, camera,
PBR tuning and interaction) to the asset. The generated generic component
fallback remains Wireup's own parametric geometry.
